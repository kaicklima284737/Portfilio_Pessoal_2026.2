Problema
O portfólio exibia repositórios recentes, não necessariamente destacados.

Prompt de correção
Pegue o projeto, e ajuste ele para que sempre acesse meu perfil de usúario de acordo com o link enviado, e pegue sempre os projetos destaques para serem adicionados.

Resultado
Resolvido parcialmente. Os seis projetos foram configurados. Seus dados são atualizados pela API. A detecção automática de mudanças nos destaques exige uma integração adicional.

Aprendizado
O prompt inicial deveria especificar a origem exata dos projetos. Também deveria exigir uma estratégia para detectar mudanças nos repositórios fixados.
